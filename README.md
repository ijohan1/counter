# counter - a simple ariphmetic game written in C

#  quick intro:
I was bored so I decided to recreate one of the old Unix games I've seen recently. The game is about simple ariphmetic. It keeps track of how many numbers you answered correctly. If you'll enter incorrect answers more than 3 times, the game will be over. 

# built with:
- C programming language
- standard stdlib and time ibraries 

# requirements:
- basic GCC in your terminal emulator or IDE to compile and run C applications

# installation & usage:
compile the main.c file and run a.out file from it.
